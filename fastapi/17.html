PSVテキスト出力3段階の読み方

要するに：読み込みは csv（標準）→ tabulate（整った表示）→ pandas（加工）の3段階です。

タカ
タカ師匠本書の例は付録のデータだ。公開されている置き場に、縦棒で区切ったファイルと、データベースのファイルがある。
タカ
タカ師匠カンマやタブで区切るのが一般的だけど、カンマはデータの中でも使われるし、タブは他の空白と見分けがつきにくい。縦棒は見分けやすく、普通の文章では珍しいので、区切りに向いている。
コードを見る（1行ずつ説明つき）
# ファイルの1行目。各列の名前を、縦棒で区切って並べている。
# 名前｜国｜地域｜説明｜別名 という並び。
name|country|area|description|aka

csv（標準の機能）

最初の数行だけを読んで表示する、いちばん単純な方法です。

コードを見る（1行ずつ説明つき）
# 区切られたファイルを読むための標準の機能を取り込む。
import csv
# コマンドで渡された文字を受け取るための標準の機能を取り込む。
import sys

# ファイル名を受け取って、中身の先頭を表示する処理。
def load(fname: str):
    # ファイルを開く。encoding は文字の扱い方の指定。日本語も扱える形にしている。
    # with を使うと、抜けるときに自動で閉じられる。
    with open(fname, encoding="utf-8") as fin:
        # 縦棒を区切りとして読む、という指定で読み取り役を作る。
        reader = csv.reader(fin, delimiter="|")
        # enumerate は、何行目かの番号と中身をセットで取り出す。
        for i, row in enumerate(reader):
            # 5行を超えたら、そこで繰り返しを終える。全部は表示しない。
            if i > 5:
                break
            # 1行分を、そのまま並びとして表示する。
            print(row)

# 直接動かされたときだけ、下を実行する。
if __name__ == "__main__":
    # sys.argv[1] は、コマンドの後ろに書いた1つめの文字。ここではファイル名。
    load(sys.argv[1])
コードを見る（1行ずつ説明つき）
# ファイル名を後ろに付けて実行する。
$ python load_csv.py cryptid.psv
# --- 実行結果 ---
# ['name', 'country', 'area', 'description', 'aka']
#   1行目は列の名前。データではない。
# ['Abaia', 'FJ', ' ', 'Lake eel', ' ']

python-tabulate（整った表示）

タカ
タカ師匠表の形での表示に特化した公開されている道具が python-tabulate だ。pip install tabulate で入る。

同じデータを、線で区切られた表として表示します。

コードを見る（1行ずつ説明つき）
# 表の形で表示する機能を取り込む。
from tabulate import tabulate
# ファイルを読むための標準の機能を取り込む。
import csv
import sys

def load(fname: str):
    with open(fname, encoding="utf-8") as fin:
        reader = csv.reader(fin, delimiter="|")
        # list() で、全部の行をまとめて一覧にする。
        rows = list(reader)
    # 先頭の行は列の名前なので、別に取っておく。
    headers = rows[0]
    # 1番目から5番目までを取り出す。最初の5件分のデータ。
    data = rows[1:6]
    # データと列の名前を渡すと、整った表として表示される。
    # title() は、単語の先頭を大文字にする指定。見出しを見やすくしている。
    print(tabulate(data, headers=[h.title() for h in headers]))

if __name__ == "__main__":
    load(sys.argv[1])
コードを見る（1行ずつ説明つき）
# 実行する。
$ python load_tabulate.py cryptid.psv
# --- 実行結果 ---
# -----------  -------  ----  -------------------  ---
# Name         Country  Area  Description          AKA
# Abaia        FJ             Lake eel
# Afanc        UK       CYM   Welsh lake monster
# Agropelter   US       ME    Forest twig flinger
# Akkorokamui  JP             Giant Ainu octopus
# -----------  -------  ----  -------------------  ---
# 列がそろい、区切りの線も入って読みやすくなっている。

pandas（本格的な加工）

タカ
タカ師匠前の2つは、ほぼ表示の整え役だ。pandas はデータを切り分けたり組み替えたりする優れた道具だ。Python の標準のデータの形を超えて、表の入れ物（表と、項目名での取り出しと、並びを合わせたもの）のような高度な形を持つ。区切られたファイルも読める。

同じファイルを、加工できる形として読み込みます。

コードを見る（1行ずつ説明つき）
# pandas を取り込む。pd という短い名前で呼ぶのが慣習になっている。
import pandas as pd
import sys

def load(fname: str):
    # ファイルを読み込む。sep で区切り文字を指定する。
    # 1行目は自動的に列の名前として扱われる。
    df = pd.read_csv(fname, sep="|")
    # head() は先頭の5行だけを取り出す。中身を確認するときによく使う。
    print(df.head())

if __name__ == "__main__":
    load(sys.argv[1])
コードを見る（1行ずつ説明つき）
# 実行する。
$ python load_pandas.py cryptid.psv
# --- 実行結果 ---
#           name country area                  description aka
# 0        Abaia      FJ                          Lake eel
# 1        Afanc      UK  CYM           Welsh lake monster
# 2   Agropelter      US   ME          Forest twig flinger
# 3  Akkorokamui      JP                Giant Ainu octopus
# 4   Albatwitch      US   PA  Apple stealing mini Bigfoot
# 左端の 0〜4 は、自動で振られた行の番号。
# この形になると、絞り込みや集計がすぐできる。
タカ
タカ師匠pandas には便利な処理が大量にある。

3つの使い分け

方法できること向いている場面
csv1行ずつ読むだけ単純な前処理。追加のパッケージが不要

🔎 具体例：pandas だと何が短くなるか

「国が US のものだけを数える」処理を考えます。csv だけなら、1行ずつ読んで、国の列を確認して、数を足す、という数行の繰り返しを書きます。

pandas なら len(df[df["country"] == "US"]) の1行です。「国別の件数」も df["country"].value_counts() の1行で出ます。データを見ながら試行錯誤するとき、この差が効いてきます。

# グラフを短い記述で描くためのまとまりを取り込む。px という短い名前で呼ぶ。
import plotly.express as px
# 返す内容を自分で組み立てるための部品を取り込む。
from fastapi import Response

# /test への GET を、この下の処理に結びつける。
@router.get("/test")
def test_plot():
    # Plotly に付属している練習用のデータを読み込む。花の測定値の一覧。
    df = px.data.iris()
    # 2つの列を、横軸と縦軸に指定して、点のグラフを作る。
    # この時点では、まだ画像にはなっていない。
    fig = px.scatter(df, x="sepal_width", y="sepal_length")
    # 作ったグラフを、画像のデータに変換する。ここで kaleido が使われる。
    fig_bytes = fig.to_image(format="png")
    # 画像のデータと、その種類を指定して返す。
    # media_type を書かないと、ブラウザが画像として表示してくれない。
    return Response(content=fig_bytes, media_type="image/png")

チャート例2：ヒストグラム頭文字ごとの件数

要するに：データから並びを作り、Plotly に渡すだけで集計と描画をしてくれます。

タカ
タカ師匠名前の項目を使って、それぞれの文字で始まるものが何件あるかの棒のグラフを作る。

実際のデータから作ります。集計は Plotly 側がやってくれます。

コードを見る（1行ずつ説明つき）
# グラフを描くまとまりを取り込む。
import plotly.express as px
# 返す内容を組み立てる部品を取り込む。
from fastapi import Response
# データを取り出すサービス層を取り込む。
import service.creature as service

# /plot への GET を、この下の処理に結びつける。
@router.get("/plot")
def plot():
    # すべてのデータを取ってくる。
    creatures = service.get_all()
    # 各件の名前の先頭1文字だけを取り出し、大文字にそろえて並べる。
    # c.name[0] は「名前の0番目の文字」、upper() は大文字にする指定。
    # sorted で並べ替えておくと、グラフの横軸がアルファベット順になる。
    letters = sorted([c.name[0].upper() for c in creatures])
    # 文字の並びを渡すだけで、同じ文字が何個あるかを数えて棒にしてくれる。
    # title は図の見出し、labels は軸の名前の指定。
    fig = px.histogram(x=letters,
                       title="Creatures by first letter",
                       labels={"x": "First letter"})
    # 画像のデータに変換する。
    fig_bytes = fig.to_image(format="png")
    # 種類を指定して返す。
    return Response(content=fig_bytes, media_type="image/png")
# --- localhost:8000/creature/plot を開いた結果 ---
# A から Z までの横軸に、それぞれの件数の棒が並んだ画像が表示される。
タカ
タカ師匠localhost:8000/creature/plot で棒のグラフの画像が表示される。

🔎 具体例：自分で数える必要がない

「A が12件、B が8件…」という集計を自分で書くなら、Counter を使って数え、その結果を横軸と縦軸に分けて渡す、という手順が必要です。

px.histogram は、["A", "A", "B", ...] のような並びをそのまま渡すだけで、数えて棒にしてくれます。集計の記述が要らない分、書き間違いも減ります。

✅ この項のまとめ

  • px.histogram() で件数の棒グラフ
  • データから並びを作れば、集計は Plotly がやる
  • 返し方は前と同じ形

マッピング例国別の塗り分け地図

要するに：塗り分け地図で国別のデータを表します。2文字から3文字への国コードの変換が必要です。

タカ
タカ師匠Plotly は基本的すぎず複雑すぎず、小さな地図を FastAPI と組み合わせるのに便利だ。
タカ
タカ師匠データは2文字の国コードで持っている。Plotly の塗り分け地図は3文字のコードを期待する。データを全部作り直すより、pip install country_converter で変換するほうが楽だ。

国ごとの件数を数えて、世界地図に色で表します。

コードを見る（1行ずつ説明つき）
# グラフを描くまとまりを取り込む。
import plotly.express as px
# 国コードの形式を変換する道具を取り込む。coco という短い名前で呼ぶ。
import country_converter as coco
# 返す内容を組み立てる部品を取り込む。
from fastapi import Response
# 同じ値が何回出たかを数える標準の機能を取り込む。
from collections import Counter
# データを取り出すサービス層を取り込む。
import service.creature as service

# /map への GET を、この下の処理に結びつける。
@router.get("/map")
def map_creatures():
    # すべてのデータを取ってくる。
    creatures = service.get_all()
    # 各件から国コードだけを取り出す。
    # if 以降で、空のものと「どこにでもいる」を表す * を除いている。
    # これらは特定の国を指さないので、地図には描けない。
    iso2_codes = [c.country for c in creatures if c.country and c.country != "*"]
    # 2文字のコードを、地図が期待する3文字のコードにまとめて変換する。
    iso3_codes = coco.convert(names=iso2_codes, to="ISO3")
    # 同じ国コードが何回出たかを数える。国ごとの件数になる。
    counts = Counter(iso3_codes)
    # 地図に渡す形に整える。keys が国コードの一覧、values がその件数の一覧。
    df_data = {"iso3": list(counts.keys()), "count": list(counts.values())}
    # 塗り分け地図を作る。
    fig = px.choropleth(df_data,
                        # どの列が場所を表すかの指定。
                        locations="iso3",
                        # どの列の値で色の濃さを決めるかの指定。
                        color="count",
                        # カーソルを乗せたときに表示する内容。
                        hover_name="iso3",
                        title="Cryptids by country")
    # 画像のデータに変換する。
    fig_bytes = fig.to_image(format="png")
    # 種類を指定して返す。
    return Response(content=fig_bytes, media_type="image/png")
# --- localhost:8000/creature/map を開いた結果 ---
# 世界地図が表示され、件数の多い国ほど濃い色で塗られている。
タカ
タカ師匠localhost:8000/creature/map で、世界地図に国別の件数が表示される。
タカ
タカ師匠米国の州ごとに描きたい場合は、地域の項目を使い、国が米国の場合に2文字の州のコードを場所として渡し、州の単位で描く指定を加える。
1

国コードを取り出す

各件から国コードだけを集める。特定の国を指さないものは除く。

2

2文字を3文字に変換

地図が期待する形式に合わせる。

変換しないと、地図に何も表示されない。

3

国ごとに数える

同じコードが何回出たかを数える。

4

地図を作って返す

場所の列と、色を決める列を指定して描き、画像として返す。

🔎 具体例：なぜ変換が必要か

データには日本を JP、米国を US という2文字で持っています。しかし地図の側は JPN、USA という3文字を期待します。2文字のまま渡すと、地図はどの国か判断できず、色が付きません。

データを全部3文字に書き換えることもできますが、他の場所で2文字を使っている部分も直すことになります。表示の直前に変換すれば、元のデータには手を触れずに済みます。

✅ この項のまとめ

  • px.choropleth() で塗り分けの地図
  • 2文字から3文字への変換に country_converter
  • 州の単位で描く指定もできる
  • Counter で国ごとに数える
