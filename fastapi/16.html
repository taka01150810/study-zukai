ブラウザの画面上で、文字を入力したり選んだりして送信するための部分です。

Form()

python-multipart

入力欄の形式で送られてきた内容を読み解くための Python のパッケージです。

クエリパラメータ

ボディ body

multipart/form-data

テンプレート template

Jinja / Jinja2

最もよく使われるテンプレートの仕組み。Flask、Django、FastAPI のどれでも使えます。

レンダリング

テンプレートに値を差し込んで、最終的な HTML を組み立てることです。

Jinja で「ここに値を差し込む」ことを表す書き方です。

静的ファイル

動的 dynamic

bgcolor

フォームForm() と、GET の落とし穴

要するに：Form() で入力欄の値を受け取ります。ブラウザの仕様上、POST にしないと正しく送られません。

タカ
タカ師匠第15章でも触れたけど、FastAPI は主に API を作るために設計されていて、初期の入力の形式は JSON だ。だからといって、昔からの HTML や入力欄を扱えないわけじゃない。
タカ
タカ師匠FastAPI は、住所や条件のときと同じように、Form という仕組みで入力欄からのデータを扱える。
タカ
タカ師匠必要なパッケージは python-multipart（入力欄の処理に必須）だ。確認用の置き場として、第15章の static/ フォルダも使う。

GET での受け取りと落とし穴

まず、入力欄から名前を受け取る窓口を作ります。

コードを見る（1行ずつ説明つき）
# 枠組み本体と、入力欄の値を受け取る部品を取り込む。
from fastapi import FastAPI, Form

# アプリ全体を作る。
app = FastAPI()

# /who2 への GET を、この下の処理に結びつける。
@app.get("/who2")
# Path や Query の代わりに Form を使う。それ以外は同じ書き方。
def greet2(name: str = Form()):
    # 受け取った名前を文章に埋め込んで返す。
    return f"Hello, {name}?"
タカ
タカ師匠主な違いは、Path や Query の代わりに Form を使うことだけだ。

HTTPie から試すと、うまく動きます。

コードを見る（1行ずつ説明つき）

# -b は本体だけを表示する指定。

⚠️ 何が起きているか

Form() は「本体の中に入力欄の値がある」ことを期待します。しかしブラウザは、method="get" の場合、入力欄の値を住所のうしろに ?name=... の形で付けて送り、本体は空にします。

結果として、FastAPI は「本体に name が無い」と判断し、422 を返します。値は届いているのに、置かれている場所が違う、という状態です。

POST に変えて解決

窓口側の動詞を変えます。

コードを見る（1行ずつ説明つき）
# 枠組み本体と、入力欄の値を受け取る部品を取り込む。
from fastapi import FastAPI, Form

# アプリ全体を作る。
app = FastAPI()

# get ではなく post に変える。これが解決の要点。
@app.post("/who2")
# 受け取り方は変わらない。Form() のままでよい。
def greet2_post(name: str = Form()):
    return f"Hello, {name}?"

画面側も、動詞を合わせます。

コードを見る（1行ずつ説明つき）
<!-- method を post に変えた。これで値は本体に入って送られる。 -->
<form action="http://localhost:8000/who2" method="post">
Say hello to my little friend:
<!-- 今回は最初の値を入れていないので、空の状態から入力する。 -->
<input type="text" name="name">
<input type="submit">
</form>
<!-- --- ブラウザで名前を入れて送信した結果 --- -->
<!-- "Hello, Bob Frapples?" -->
<!-- HTTPie で試したときと同じ結果になった。 -->
タカ
タカ師匠ブラウザで取り直して名前を入力すると、HTTPie のときと同じ結果になる。結論は、HTML のファイルから入力欄を送るときは POST を使う、だ。
❌

method="get"

値は住所のうしろに付き、本体は空になります。Form() では受け取れず、422 が返ります。

避ける
✅

method="post"

値は本体に入って送られます。Form() で正しく受け取れます。

🔎 具体例：どうしても GET で受けたい場合

検索の窓口のように「結果の住所をそのまま共有したい」場合は、GET のままにしたいことがあります。その場合は、受け取る側を Form() ではなく Query()（あるいは何も付けない）に変えます。

つまり「入力欄が値を住所のうしろに付けてくる」という動きに、受け取る側を合わせる、という解決の仕方です。どちらに合わせるかは、住所を共有したいかどうかで決まります。

  • GET と POST の使い分けが身につく

✅ この項のまとめ

  • Form() で入力欄の値を受け取る
  • python-multipart が必要
  • HTML の入力欄は method="post" が基本

テンプレートを使う

テンプレートに値を渡して、組み立てた HTML を返す窓口です。

コードを見る（1行ずつ説明つき）
# 枠組み本体と、届いた問い合わせそのものを表す型を取り込む。
from fastapi import FastAPI, Request
# テンプレートを扱う部品を取り込む。
from fastapi.templating import Jinja2Templates
# 表示するデータの取り出し元を取り込む。仮のデータを使う。
import fake.creature as creature_data
import fake.explorer as explorer_data

# アプリ全体を作る。
app = FastAPI()
# テンプレートの置き場所を指定して、使えるようにする。
templates = Jinja2Templates(directory="template")

# /list への GET を、この下の処理に結びつける。
@app.get("/list")
# request を引数に書くと、届いた問い合わせそのものが渡ってくる。
def list_them(request: Request):
    # テンプレートの名前と、渡す値の組み合わせを指定して返す。
    return templates.TemplateResponse(
        # 使うテンプレートのファイル名。上で指定したフォルダからの相対の名前。
        "list.html",
        {
            # request は必ず入れる。Jinja が内部で使うため、無いとエラーになる。
            "request": request,
            # テンプレートの中の creatures に、この一覧が渡る。
            "creatures": creature_data.get_all(),
            # 同じく explorers に、この一覧が渡る。
            "explorers": explorer_data.get_all(),
        },
    )
# --- ブラウザで localhost:8000/list を開いた結果 ---
# 生き物の表と、探検家の表が並んだページが表示される。
タカ
タカ師匠置き場所を指定して使えるようにし、テンプレートの名前と、渡す値の組み合わせを指定して返す。request は組み合わせの中に必ず入れる（Jinja が内部で使う）。
タカ
タカ師匠前の章の仮のデータを使っている。データベースが空でも、つながっていなくても動く。
タカ
タカ師匠ブラウザで http://localhost:8000/list を開くと、2つの表が組み立てられて表示される。

🔎 具体例：テンプレートを使わないとどうなるか

テンプレートを使わず、Python のコードの中で HTML の文字列を組み立てることもできます。しかし "<tr><td>" + name + "</td></tr>" のような書き方が並ぶと、どこが表の形で、どこが値なのかが読み取りにくくなります。見た目を1か所直したいときも、Python のコードの中を探すことになります。

テンプレートに分けておけば、表の形は HTML のファイルの中だけにあります。見た目の調整は HTML を触る人が、データの用意は Python を触る人が、それぞれ独立して進められます。

第1問Form() の使い方

FastAPI で入力欄の name の値を受け取る処理を書いてください。必要なパッケージを入れるコマンドも併せて書いてください。

✅ 解答例
pip install python-multipart で必要なパッケージを入れる。そのうえで from fastapi import FastAPI, Form と書き、@app.post("/greet") の下に def greet(name: str = Form()): と書いて、受け取った値を使う。python-multipart が入力欄の処理に必須。Form() を引数の初期値の位置に書くと、送られた値が引数に入る。
📝 採点ポイント
□ pip install python-multipart を書いている
□ Form を取り込んでいる
□ 引数の初期値の位置に = Form() を使っている
第2問GET の入力欄の落とし穴

ブラウザで入力欄の method="get" を使うと、なぜ FastAPI で受け取れない（422 になる）のですか？ 解決の方法は何ですか？

✅ 解答例
HTML の決まりで、GET で送るときは入力欄の値が住所のうしろの条件として付けられる（もとからあった条件は消される）。Form() は本体の中に値があることを期待するが、GET では本体が空になるため「その項目が必要」という 422 が返る。解決の方法は method="post" に変えること。POST なら入力欄の値が決まった形式で本体に入り、Form() で正しく受け取れる。
📝 採点ポイント
□ GET では値が住所のうしろに移ることに触れている
□ Form() が本体を期待する仕組みに触れている
□ 解決の方法（POST に変える）を述べている
第3問Jinja2 の基本の書き方

Jinja2 のテンプレートで「値の差し込み」と「一覧の繰り返し」を書く基本の形を、例とともに説明してください。

✅ 解答例
値の差し込み：{{ 変数名 }} のように二重の波かっこで囲む。例：<p>Hello, {{ name }}!</p>。一覧の繰り返し：{% for item in items: %} … {% endfor %} で囲む。その中で {{ item.field }} などを使う。{% %} は処理を書くためのもの（条件、繰り返しなど）、{{ }} は値を差し込むためのもの、という違いがある。
📝 採点ポイント
□ {{ 変数 }} で差し込む書き方を示している
□ {% for %} ... {% endfor %} で繰り返す書き方を示している
□ 両者の役割の違い（差し込み と 処理）に触れている
第4問テンプレートを返すコード

FastAPI で template/list.html を creatures という値とともに組み立てて返すコードを書いてください。

✅ 解答例
from fastapi import FastAPI, Request と from fastapi.templating import Jinja2Templates を書き、templates = Jinja2Templates(directory="template") で置き場所を指定する。窓口の処理は def list_creatures(request: Request): とし、return templates.TemplateResponse("list.html", {"request": request, "creatures": creatures}) と書く。渡す値の組み合わせには request が必須（Jinja が内部で使う）。
📝 採点ポイント
□ Jinja2Templates の取り込みと置き場所の指定に触れている
□ TemplateResponse の使い方を正しく書いている
□ request を渡す値に含めている
第5問静的ファイルとテンプレートの違い

第15章の StaticFiles と、本章の Jinja2Templates、どう使い分けますか？

✅ 解答例
StaticFiles は内容が固定されたファイル（HTML、装飾、画像など）をそのまま配信する仕組み。サーバ側で内容を変えない。Jinja2Templates は、値の差し込み口を持つ HTML を、問い合わせのたびに組み立てる仕組み。データベースから取ったデータを表示するなど、内容が状況によって変わる場合に使う。両方を一緒に使うこともでき、テンプレートの中から /static/style.css のような固定のファイルを参照するのは一般的。
📝 採点ポイント
□ 前者が固定の内容、後者がその都度の組み立て、と述べている
□ 使い分けの基準（内容が変わるかどうか）に触れている
□ 一緒に使えることに触れている
