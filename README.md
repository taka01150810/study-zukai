# Study 図解

読んだ技術書の内容を、専門用語を極力使わずに図で読める形にまとめた学習ノートです。

**公開ページ: <https://taka01150810.github.io/study-zukai/>**

## 中身

各ページは外部の CSS / JS / フォントを一切読み込まない、単体で完結した HTML です。
ダウンロードしてローカルで開いても同じように表示されます。

| ディレクトリ | 書籍 |
| --- | --- |
| `ddia/` | データ指向アプリケーションデザイン |
| `fastapi/` | FastAPI |

`build.py` の `BOOKS` には他の書籍（Terraform / LangChain）も登録されていますが、
Vault 側に図解が無い間は出力されません。図解を置けば次のビルドで自動的に復活します。

## 更新のしかた

図解の原本は別の（非公開の）Obsidian Vault 側にあります。
章を書き足したら、このリポジトリで以下を実行すると、HTML のコピーと目次の再生成がまとめて走ります。

```bash
python3 build.py
git add -A && git commit -m "図解を更新" && git push
```

push すると GitHub Pages に自動で反映されます（反映まで1〜2分）。

新しい書籍を追加する場合は、`build.py` の `BOOKS` にフォルダ名とスラッグを1行足してください。

## 注意

書籍の本文そのものではなく、学習のために自分の言葉で要約・再構成したノートです。
正確な内容は各書籍の原典を参照してください。
